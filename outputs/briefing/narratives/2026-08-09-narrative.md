## AI Application Infrastructure

Recent developments address different parts of the architectural problem in AI application infrastructure. Amazon Bedrock AgentCore has announced runtime instances that provide persistent compute infrastructure, supporting multi-agent collaboration and GPU acceleration. Amazon DynamoDB now supports real-time vector search. Applications can store vector embeddings alongside operational data in DynamoDB and run similarity searches directly against that data.

## Compute/Platform Foundation Developments

Amazon EC2 R8i and R8i-Flex instances are now available in the Europe (Milan) region. According to AWS, R8i and R8i-flex instances provide up to 15% better price-performance compared with previous generation Intel-based instances. According to AWS, R8i and R8i-flex instances deliver 20% higher performance than R7i instances, including up to 30% faster performance for PostgreSQL databases, up to 60% faster for NGINX web applications, and up to 40% faster for AI deep learning recommendation models compared to R7i instances.
